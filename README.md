# Enchanted by Jo, new store

The rebuilt enchantedbyjo.com shop. Plain HTML, CSS and JavaScript, with Supabase as the database and login, hosted on Netlify.

- `index.html` — this week's market (shop page)
- `css/styles.css` — brand colors and layout
- `js/config.js` — public Supabase address and publishable key (safe to be public)
- `js/basket.js` — remembers the basket on the shopper's device
- `js/shop.js` — loads products from Supabase and draws the shop
- `signin.html`, `basket.html` — placeholders for the next build steps

Never put the database password, secret key, or Resend key in this repository.
